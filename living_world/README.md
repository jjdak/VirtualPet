# 两个角色的实时小世界

## W2 晴天和雨天

运行 `./living_world/w2.command`，打开 <http://127.0.0.1:4194/>。默认从暂停状态开始。可从零观察，或点击“载入双人示例”进入第 700 步，看两人下一次如何选择。天气按 80 步交替，玩家可固定天气、恢复交替、改变当前天气的食物效果、修改共同供给或只给一个角色线索。W2 使用 `.runtime/living-world-w2/` 保存两套个人经验。W2 复核命令见[本阶段进展](../docs/sim/living-world/w2/PROGRESS.md)。

## 启动

在项目根目录运行：

```sh
./living_world/run.command
```

随后打开 <http://127.0.0.1:4193/>。也可以双击 `run.command`。仅使用已有 Python 标准库；实测 Python 3.14.4，没有包安装、云请求或模型加载。需要整个仓库：核心读用冻结的 `experiments/adaptive_agents/src/core.py`。

启动时世界暂停；有自动存档则恢复它。按“开始生活”运行，“暂停”停止，暂停后可以逐步推进，速度支持 1×/2×/4×。关闭页面不会停止服务，离开前请暂停；停止启动窗口中的服务可按 Ctrl-C。电脑睡眠期间不补跑大量历史步数。

## 可以做什么

- **改变环境**：分别设置青禾地、紫穗地是否开放，以及食物有益/食后不适。地图显示导演所见真值；角色只在距离不超过一格时观察供给，只有到达食物点取食才获知效果。
- **给一个人线索**：选阿禾或小岚，再选地点。建议是短期偏好，不改变亲历价值、不会强制打断在途任务；约 100 步有效，到访结束。重复建议替代旧待办，不叠加分数。
- **查看独立经历**：切换角色，查看亲历、同伴消息、建议、行动理由与需求。对同伴的信任须经自己的取食结果验证，收到消息本身不增加亲历次数。
- **保存**：三个手动槽和自动档；存档包含双方记忆、需求、位置、途中任务、时钟、种子和消息去重。读取/导入后暂停。Chromium 已验证从页面下载 JSON，再通过文件选择器导回同一文件，恢复后的完整世界状态与导出前一致。

一个观察办法：先给阿禾紫穗地线索，让它亲自尝到不适，再将紫穗地改为有益。看看后来到访的小岚如何获得不同经验，两个人交换消息后是否改变选择。这不是保证成功的剧情；具体行动由当时需求、记忆、建议和固定种子的探索决定。

## 本地数据与恢复

默认存档在 `.runtime/living-world/`，被 Git 忽略：

- `autosave.json`：每 20 步及成功控制操作后更新；启动自动读取。异常终止可能丢失最近不足 20 步。
- `slot1.json`–`slot3.json`：手动槽。再次保存同一槽会覆盖，其他槽不动。
- `before-restore.json`：最近一次读取、导入或新建前的恢复副本。需要恢复时可经 JSON 导入；请保留副本后再导入，因为该文件会轮换。

核心字段保留，个人文字记录最近 80 条、世界日志最近 200 条、玩家线索最近 20 条；不是无限日志归档或完整事件回放。长期价值、亲历次数、同伴可信度不会因文字截断而清空。速度与开始/暂停是运行控制，读档始终暂停。

如端口占用，可用 `./living_world/run.command --port 4194`。独立测试可用 `--save-dir /tmp/w1-test-saves`；不要让两个实例共用同一存档目录。损坏自动档会拒绝启动，先保留文件，再用手动槽或导出文件恢复，不会静默清空。

## 复核

```sh
python3 living_world/src/verify.py
node --check living_world/web/app.js
```

15 项检查含临时回环 HTTP 监听、3,000 步行动审计、400 步完全一致续跑、新进程恢复、坏档事务性拒绝、真实时钟和暂停。受限沙箱可能需要允许本机端口监听。回执写入 `docs/sim/living-world/review/`，首次内置浏览器记录与后续独立 Chromium 验证分别保留。

## 复核浏览器文件与控制

需要 Node、Playwright 1.62.1 和配套 Chromium Headless Shell。测试自动启动临时服务并使用临时存档目录。在仓库根目录，设置 `PLAYWRIGHT_MODULE_PATH` 为已安装的 playwright 模块目录，`PLAYWRIGHT_BROWSERS_PATH` 为浏览器缓存目录，然后运行：

```sh
node living_world/tests/browser-check.cjs
```

这会更新 [浏览器回执](../docs/sim/living-world/review/browser-verification.json) 和两张界面截图。存档导入、读档和新建会显示页面内确认框。慢请求期间控制按钮锁定，超过 8 秒会提示结果待核对并恢复状态查询。

## 实现与边界

`src/world.py` 是无 UI 核心；`src/server.py` 是只监听回环地址的服务/时钟/存档；`web/` 是原生 Canvas/HTML/CSS/JS；`tests/` 是信息边界与恢复测试。

角色地图/食物坐标预先已知，路径由固定 BFS 提供；两角色允许同格经过，没有身体推挤碰撞。饥饿增加，取食降低饥饿，休息恢复精力，没有死亡。距离不超过两格自动交换最近亲历，不是自主学会社交。双方使用相同规则，但有独立记忆、位置和需求；初始饥饿差异也由我们设定。食物效果为确定的 ±1，未移植 E3–E6 全套复查机制。无 LLM、训练、自创技能、情境泛化、世界分支或 Godot 对接；趣味性仍待用户体验。
