      完整 W2 v2 存档分别恢复成两个独立世界，天气与随机选择规则同步。只在右侧分支时给指定角色追加一条建议；以后两边自行推进，没有连续干预。重新分支每次都回到同一原档，不接着上次的终点运行。

      “行为不同”只比较同一步的位置、行动阶段、当前目的地；日志或收到建议本身不计入。首次与最后差异、差异步数都在 +0…+240 的窗口内。“最后差异”并不保证之后永远相同；末步仍不同表示观察截断。“建议结束后”从建议结束的下一步开始统计。

      “同一步改选”指两边同一步出发、却选了不同地点的次数。亲历报告差异比较实际送达内容和时间；同伴受影响的传播证据还需关闭双方后续交流重复比较，保留原档已有消息。先后关系本身不能证明因果。

      默认示例取固定网格顺序中首个有传播证据的案例；若没有则取首个直接行为改变案例。它用于查看机制，不能代表平均效果。也可以载入未按该规则筛选的 W2 第 700 步示例。“效果互换”来自单独的场景组：分支前已交换两处食物效果，两个分支从同一份变化后的存档开始；不是主网格的自然发生率。
