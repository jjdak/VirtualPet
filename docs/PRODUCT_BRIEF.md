# 产品简报：菲比私人同人原型

## 一句话

一个不要求照料、不制造亏欠感，只通过触摸、动作和活泼吐槽回应用户的跨设备角色陪伴 App。

## 使用边界

- 菲比同人原型
- 仅私人、非商业测试
- 公开仓库只包含代码和原创占位素材
- 不复刻官方或短视频平台的原始语音文件
- 若未来公开分发、商业化或上架，重新确认角色、美术、声音和商标的授权范围

## 设计原则

1. 角色优先：屏幕的大部分空间属于角色，不属于仪表盘。
2. 不惩罚离开：没有饥饿、掉血、死亡、连续签到或待办红点。
3. 直接互动：主体验是触摸角色，不是进入菜单操作。
4. 动作先于功能：每个新增按钮都必须对应明确的角色表现。
5. 吐槽不攻击：活泼、俏皮、有一点嘴硬，但不让用户感到被否定。

## V0.3 已实现

- v3 造型待机图的本地私有接入
- 帽子、摸头、戳身体、三连点和长按
- 待机、啾比与夜间困倦状态
- 原创吐槽文案
- iOS/watchOS 触觉反馈
- 私有音频可选加载位
- iPhone/iPad/Mac 共用布局
- Apple Watch 专用紧凑布局

## 暂不进入

- 成长、等级、养成数值或经济系统
- 任务、签到、社交、公会、战斗
- 聊天历史、账号、云端同步
- 公开分发同人素材
- 在动作手感未确认前制作大批量动画帧

## 下一次评审只看三件事

1. v3 在真实窗口和手表尺寸上是否仍然像菲比，尤其是脸型与下巴。
2. 帽子、头部、身体和长按的反馈是否一眼能读懂。
3. 原创“啾比”音色与参考节奏的距离是否可接受。
