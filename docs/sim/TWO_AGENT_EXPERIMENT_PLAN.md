# E1：两角色经验与传播实验

日期：2026-10-27。用户授权：实现两个角色的小实验，对比本机 0.6B/1.7B，记录经历影响与经验传播。不是完整村落、人体运动学习或语言模型训练。

## 先回答的问题

1. 相同观察下，个人经历是否改变选择？
2. 乙没有亲历且看不到甲的活动时，是否保持原判断？显式通信后是否能利用甲的经历？
3. 清除记忆、反转效果、交换位置后，变化是否仍符合证据？
4. M4 / 16 GiB 上，两种同系列、同 4-bit 量化模型的延迟、吞吐、模型进程内存如何？

## 冻结的第一轮协议

- 独立 Python 网格世界，两个角色、两处食物；共享动作协议与模型权重，每人独立记忆。不调用云模型，不改原 Godot 或 Blender 工程。
- 原子动作：移动一格、取食、近距离告知。移动受边界/障碍约束；取食要求到达；结果由世界的隐藏规则产生。模型只选择取食目标，由公共控制器执行移动/取食，不能自行宣称动作成功。
- 局部信息：角色只能收到当前可见食物、自己经历、收到的消息。甲采样时乙离开感知范围；不能通过共享模型获得其他角色记忆。
- 使用 12 个固定世界，交换标签、左右位置及有害/有益对应关系。所有后端使用相同输入协议。健康结果为 +4/-4；位置到食物的距离相同，减少距离偏好。
- 每个世界的八个探针：甲无经验、乙无经验、甲亲历后、乙隔离后、乙接收经验后、甲清空记忆、甲接收相反的真实经历、甲的食物位置交换后。探针使用独立快照，决策执行结果不污染后续对照。
- 控制暴露：实验员安排甲取食两类食物，随后安排甲向乙发送两条真实记录。首轮**不检验自主探索、主动分享或自由语言交流**，只检验经验利用与可传递性。
- 对照策略：无语言模型的经验价值估计（以观测到的健康增量估计每类食物价值；保留直接/转述来源）。它在此任务上很可能足够好，作为复杂度下限，不包装成训练出的通用智能。
- 模型：`mlx-community/Qwen3-0.6B-4bit` 和 `mlx-community/Qwen3-1.7B-4bit`，固定实际下载 revision；关闭 thinking、贪心解码、相同提示、最多 48 个输出 token、无自动纠错/语义重试。无效输出单独报告，不用安全兜底掩盖模型失误。
- 记录原始提示、输出、动作事件、运行配置和延迟；初次加载/预热与热运行分开；顺序运行两个模型，不把单模型顺序吞吐称作多角色并发或含渲染性能。

## 实施顺序与验收

2026-10-31 限定诊断：v2 两种模型在亲历/转述后均为 6/12 有益选择，反转经历后均不改变选择。增加唯一一轮输入编码对照 E1-v3：把相同局部观察和健康增减记录转成中文句子，其他世界、提示目标、采样、权重和动作不变；两模型和价值表各运行原 96 探针。记录为探索性诊断，不覆盖 v2，也不称为独立留出集。无论结果如何，完成此轮后停止调提示，汇总证据。

运行中协议修订：E1-v1 的 0.6B 96 次输出均带 JSON 代码块，被严格解析拒绝；完整原始协议和输出保留于 `experiments/two_agents/results/e1-v1/`。1.7B 同样先完成 v1。E1-v2 只统一接受单个 JSON 代码块外壳，不修改载荷、不纠正目标、不重试，并单列严格 JSON 合规数。两个模型完整重跑同一批输入，避免用不同解析方式比较。此格式修改不构成行为学习。

1. [x] 隔离依赖、固定权重来源，记录环境。
2. [x] 世界、隔离记忆、通信、对照策略；5 项世界/接口测试通过。
3. [x] 两模型完成同一 96 次决策测试，v2/v3 各 288 次含价值表，保留全部输出与耗时。
4. [x] 生成离线对照回放与[结果报告](TWO_AGENT_EXPERIMENT_RESULTS.md)，576 次轨迹复核通过；实际浏览器播放/视觉验收仍待完成，内置 webview 连接超时。

预设观察指标：合法目标输出率；亲历/通信/相反经历/位置交换后的有益选择率；隔离乙的选择一致率；清除记忆与初始选择一致率；真正发生选择改变的配对数。12 个世界是小样本筛选，不作统计显著性或泛化智能结论。

## 身体、世界与独立主角

不要求语言模型：行为可以来自价值表、小网络或规则。自然语言模型的增益需要由任务证明。

后续若引入 3D，继续用 Godot 负责碰撞、重力、导航和动画；代理调用带前置条件与执行反馈的 `move_to / eat / tell / wait`。从零训练肌肉、平衡或步态属于另一项高成本研究，不是实现可信物理的前提。

候选架构：普通 NPC 共享基础模型，个人记忆与价值估计独立；主角增加可更新的个人策略或适配器。共享权重与独立成长兼容；“进化”需要具体定义为经验、价值更新或权重训练，不能混称。此轮只实现独立经验与价值估计，不训练语言模型或主角适配器。
