# S2：动作打断与场景控制

2026-10-23。用户授权记录 LLM 反馈思路，并继续优化场景控制。本轮保留现有场景/光色/人物/动作素材，没有进入美术重制或接入模型。

## 已记录的方向

[LLM_FEEDBACK_DESIGN.md](LLM_FEEDBACK_DESIGN.md)：白板世界可以作为验证载体；先局部结构化观察和引擎实际动作结果，视觉/混合输入后置。角色只能知道自己感知过的信息，旧观察带时间；引擎持有事实，模型选择有限技能。事件驱动请求，不逐帧调用，也不实施强化学习。已同步 SIM_STAGE_PLAN。

## 本轮操作变化

- 转身中松键，停止继续旋转；换方向，取消原转身并响应新方向。
- 停步途中再次输入方向，可以提前续走，不必等原 1 秒片段结束。
- 人工接管“去池边”时，取消正在执行的转身/停步位移，避免目标已取消而身体继续旧动作。
- 新增 **Space / 停下按钮**：取消人物当前目标和动作；方向键仍按住时不立刻重启，松开后可重新操作。世界不暂停，纸船继续漂流。
- 窗口失焦会停止人物、取消自动目标并释放输入；第一视角 Esc 也会停止当前动作、释放鼠标。焦点恢复不会自动恢复旧目标。
- 离开原坐姿参考，不再恢复进入预览前尚未结束的转身/停步片段。

中断时先停止根位移，暂留当前动作姿态并在约 0.15 秒内淡出；约 0.18 秒过渡窗口防止下一动作立刻覆盖尚未淡出的姿态。当前朝向继续作为后续起点。大角度尚未对准时允许移动速度降到 0，避免强制沿错误方向前进。

这只是本地控制改进，**不是完整 S3 控制协议**：还没有局部观察接口、控制世代号、异步模型回复、事件回放或 AI/HUMAN/PAUSED 控制器。

## 验证

新增 `sim/tests/control_checks.gd`，经无窗口和图形模式检查，均退出 0、`passed=true`。测试走实际输入状态、控制处理与物理帧，但不等同于用户手动操作验收。

- 转身中松键后 0.22 秒：原动作退出，朝向额外漂移 0。
- 停步中重新输入后 0.25 秒：Stop 退出并恢复非零移动速度。
- 改向后 0.12 秒：旧转身退出；图形样本朝向变化约 0.202 rad，没有瞬间跳到新目标角度。
- Space 后保持方向键 0.4 秒：人物水平位移 0；纸船仍前移，松键后新输入可以继续操作。
- 自动动作中的接管、失焦、坐姿来回切换、第一视角 Esc 检查通过。
- 完整图形 S2 回归通过：现成转身角度/停步、接触统计、去池边、墙体阻挡、人工接管、重置、相机和纸船阻挡/释放等均通过。池边终点误差约 0.064 m。
- 视频完整解码和代表帧检查；无新增素材/工具依赖，原 Blender 源未改写。公开树检查在提交前执行。

## 限制与下一项

脚步相位匹配、左右 Stop 选择、180° 转身的完整素材尚未补齐；可打断提高响应，但频繁改向仍可能出现姿态衔接不顺或滑脚。Space 是明确取消身体指令，不是完整物理刹车表演。碰撞路径仍为直达目标与失败返回，没有通用绕路。画面质量和主观手感待用户体验。

下一项按已确认路线定义 S3 的局部观察和动作结果接口，先提供可检查的角色已知信息与控制交接，再接真实 LLM；视觉与完整美术还原可以后置。不得把本轮控制测试通过当作 S3/S4 完成。
