# LLM 如何获得世界反馈：已确认的方向

2026-10-23。用户接受先用白板世界验证，并要求记录本思路、继续优化控制。**本文件是后续 S3/S4 设计，感知接口与真实 LLM 尚未实现。** 当前庭院继续作为可玩载体，不因此删除原美术或重建场景。

## 输入与输出

第一版采用「局部结构化观察 + 实际动作结果」。第一视角是角色的观察位置/范围，不要求先用视觉模型解析截图。先验证基于不完整信息的决策与行动闭环，再按需要加入截图或混合感知。

引擎真实状态 → 角色可感知信息 → LLM 选择有限技能 → 引擎执行/碰撞 → 返回可验证的动作结果和新观察。

- 观察：当前视野内的物体、距离/方向、可见运动变化；用距离、视锥与遮挡筛选。
- 身体反馈：自身位置/朝向、移动是否受阻、执行到哪一步。
- 动作结果：成功、失败、被人工取消，附实际到达位置、耗时和可感知的失败原因。
- 记忆：保留带时间的旧观察和已执行事件，明确“现在可见”和“之前见过”；不直接复制全局世界状态。
- 输出：有限的 `look_at / move_to / interact / wait`，以执行器当时支持的能力为准。不得让模型文字直接修改物体或宣布成功。角色手部清障仍未实现，不能在接口中假装可用。

## 纸船例子（未来协议示意）

1. 观察：“前方约 3 米有纸船，连续两次观察位置没有变化，旁边可见树枝。”先给可观察现象，不预先告诉模型完整任务答案。
2. 选择：“走到池边的已知位置。”
3. 执行：“成功，到达位置……，距纸船 0.8 米。”或“失败，移动被碰撞阻挡。”
4. 新观察：近处能看清纸船与树枝的接触关系；模型决定观察、等待或调用已支持的交互。
5. 用户在背后移走树枝：未被看到/听到的变化不自动通知角色；回头再观察才更新认知。

这里的“听到”只是未来感知通道设计，当前不新增声学系统。物体身份、位置和内部状态的可见粒度需在 S3 明确定义。

## 权限、时间与事实边界

- 世界状态仅引擎知道；角色只能收到经过筛选的观察。调试面板可以显示全局状态，但不得混入模型输入。
- 目标离开视野后只能保留最后已知位置，不能通过目标 ID 持续获取其真实坐标。无法确认目标时报告失去视觉联系，而不是泄露“背后的物体已被删除”。
- 动作绑定 `action_id / observation_id / control_epoch`；接管后递增控制世代，迟到模型回复不得重新夺回身体。
- 动作结束、执行失败、重要可感知变化时才请求新决策；逐帧走路、转身和物理由引擎执行。模型等待期间世界继续运行。
- 先有限事件记录和规则策略，再接同一接口的 LLM；不训练、不更新模型权重，不把反馈闭环称作强化学习。

## 实施顺序与检查

1. 继续 S2 操作手感：转身/停步可打断，人工接管可靠，停下与重置清晰；本轮优先这部分。
2. S3：建立局部观察、动作结果和控制交接；调试视图显示“她知道什么/不知道什么”。验证背后变化不泄露、遮挡生效、旧记忆不冒充当前事实、过期动作不恢复控制。
3. S4：接真实 LLM，限制技能和调用预算，对比固定规则在相同干预下的行为。不提前选定模型/费用或假定授权密钥。
4. 当文字观察闭环成立，再比较第一视角截图或混合输入是否带来额外价值。保留相同场景/事件进行对照，将识别错误与决策错误分开记录。

美术完整度不是上述验证的前置条件；当前允许简化画面，但不把技术通过视为静谧感、角色自主性或用户体验已经成立。
