# 三对游程的出发选择 · 先行计划

2026-11-10。先核对并保存游程诊断归档，再按以下方案分析。

1. 从归档 diagnosis.json 锁定 classification 为 place_difference 的全部角色，用 best_alignment 中 same_place 为假的配对确定两侧出发时刻和地点。分别复原三对的起始存档和游程诊断，并对照已记录的原始结果。以每一侧真实出发时的绝对时钟做分析。
2. 在原选择函数入口捕获个人状态。此时当步天气、近期消息的可信度衰减和观察已更新，该角色本次取食及本步结束时收信尚未发生。记录当前天气的个人估计／次数、最近一次取食、同伴消息内容／来源／年龄／有效权重、供给、有效线索、选择前一趟目的地。验证原始得分、候选地点、执行的规则和随机抽样。区分首次尝试、分数并列、按估计选取、随机探索。
3. 在每个决策的独立副本上运行原选择函数。固定时钟、可选地点、亲历次数、有效线索及两个随机抽样。交叉打开/关闭三个因素：亲历估值（关闭时分数置零，保留已尝试的事实）、同伴消息（清空此刻收件箱）、探索（阈值置零）。比较完整 8 个组合。区分改变分数、打破并列、足以使地点翻转及多个信息来源给出相同建议。
4. 单独互换两个分支出发时的随机输入，保留各自记忆和消息年龄。检查两边使用同一组抽样时是否仍会分岔。对重复种子的两个提示条件保留独立列项，注明其决策时钟与抽样是否重复。
5. 记录每个真实决策、一次性反事实结果和判断依据。结论限定为当时选目标的直接机制。复现脚本放在 living_world/studies，本轮证据与进展归入本目录。
