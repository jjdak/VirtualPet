# W3 同档分支计划 · 2026-11-09

W2 成果和远端回执已先归档。W3 使用 W2 的世界和随机选择规则，两边各自恢复同一份完整 v2 存档，时钟同步推进。分支时只在右侧发一条指定地点建议给一名指定角色。其后让两边自行生活。

## 运行前固定的比较

- 种子 0–31，自主运行到 0、60、180 步存档。每个存档交叉两名收件人、两个建议地点，共 384 对。每对跟踪 240 步。另复核同档无干预能逐步复现，针对中途存档保留天气、在途任务、两套个人经验。
- 按同一时刻比较各人的位置、阶段和当前目的地。报告首次差异、最后观测差异、差异步数、间断、末步是否仍不同。另记两边同一步出发但选择不同地点的次数。只收到建议或多一条日志不算行为改变。
- 记录建议在右侧到访结束或到期的时刻，并检查这之后还有没有行为差异。仍有差异的末步视为观察截断。两个条件、不同分支年龄的结果分开报告，空结果保留在分母中。
- 对比另一人实际收到的亲历报告，包括缺席、不同地点、结果、采样时刻或送达时刻。跟踪报告差异、同伴首次行为差异的先后。每组再从同一存档关闭双方后续通信重复成对比较，保留分支前已有的消息。由此检查同伴差异是否依赖后续交流。
- 制作本机双世界对照页，可从给定示例或导入的 W2 存档分支，选择收件人和地点，重算后并排查看同一步的状态及关键时刻。展示样例取固定网格顺序中首个有传播证据的案例，若没有则取首个直接行为改变案例；明确样例的筛选规则。
- 核验存档隔离、同种子同步、单次建议、传播路径、视窗边界、页面实际操作。W3 代码归入 living_world，证据和进展在本目录，运行时个人存档继续本地保存。

## 主比较完成后的补充方案

主比较 384 对中出现 65 对报告差异，同伴行为差异为 0。基于这一结果，补充使用 W2 已有的第 480 步晴天效果互换流程。此处在运行补充比较前固定种子 0–31、分支时刻 480 和 700、双方收件人和两个地点，跟踪 240 步，共 256 对。两边共享同一份已发生效果互换的历史，分支之后仅给一条建议。单独报告补充结果及首个满足传播标准的实例，不与主比较合并估算发生率。
