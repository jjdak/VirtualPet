## 固定主比较

32 个种子分别从空记忆自主生活到 0、60、180 步。每份存档独立恢复为两个世界，对两名角色、两个推荐地点逐一测试。左侧自由运行，右侧用 W2 原有规则向一个人发送一次建议。两边使用相同的天气时钟、环境规则与按角色及绝对步数生成的随机选择。共 96 份起始存档、384 个配对条件。每个条件另跑一组通信关闭对照。

| 分支时刻 | 配对数 | 收件人行为不同 | 送给同伴的报告不同 | 同伴行为不同 |
| --- | ---: | ---: | ---: | ---: |
| 第 0 步 | 128 | 64 | 64 | 0 |
| 第 60 步 | 128 | 1 | 1 | 0 |
| 第 180 步 | 128 | 0 | 0 | 0 |

按“阿禾／青禾、阿禾／紫穗、小岚／青禾、小岚／紫穗”四种条件，每种 96 对，直接行为改变分别为 18、15、17、15 对。319 对全程没有观察到收件人行为差异。381 条线索以到访结束，3 条到期。到访包括角色本来就要去该地的情况。

在有直接改变的 65 对中，首次差异的中位数是 +8，最后观察到差异的中位数是 +74，实际有差异的步数中位数为 44。65 对都曾暂时恢复相同状态，又出现差异。建议结束之后的差异步数中位数为 37。末步仍有差异的为 1 对。这 65 对建议结束后均未再次观察到“两边在同一步出发却选不同地点”，路径、需求节奏和不同步出发仍可能造成行为差异。

所有主比较都从晴天分支，其后正常交替天气。所有配对累计观察晴天 50,816 步、雨天 41,344 步，收件人行为不同分别为 3,302 和 106 步。240 步的末端是本轮观测上限。记录中的“最后差异”只描述这段窗口。[统计与分层](review/summary.json) · [逐对结果](review/pairs.jsonl)

| 第 700 步 | 128 | 19 | 19 | 2 |

在直接改变的 62 对中，实际行为差异步数中位数为 135，38 对在 +240 仍不同。在 18 对同伴改选中，同伴首次行为差异中位数为 +66，13 对在观察末步仍不同。这 18 对同伴都在建议到访结束或到期后发生过同一步的不同地点选择。关闭后续交流的 256 组成对对照中，同伴行为差异为 0 组。以上比例描述这组固定条件，四个提示条件共享起始存档。[补充统计与逐对结果](review/reversal.json)

## 计量、复现和验收

- **直接或同伴行为差异**比较同一步的格子、行动阶段及出发目标。回营时目的地是各自营地。日志编号、建议文本、已送达消息和单纯内部估计变化均排除在行为计数之外。
- **报告差异**比较收件人向同伴成功送达的亲历，包括采样时刻、天气、地点、结果和是否在该步送达。发送给同伴的是角色的取食亲历。建议留在玩家指定角色的个人记录中。
- **传播判据**要求报告先有差异，随后同伴有行为差异，窗口内存在同伴同一步选择不同地点，且关闭后续交流的配对中同伴行为一致。静默对照保留存档内已有的消息。
- 页面保留每个不同区间、差异时刻和末步截断状态。自带主示例按固定规则选取，为种子 0、第 0 步向阿禾推荐青禾地。同伴收到不同报告且行为一致，适合与传播案例对看。导入的 v2 存档如已有未完成建议，右侧沿用 W2 的新建议替代规则。
- 从仓库根目录运行 `python3 living_world/studies/w3_influence.py` 与 `python3 living_world/studies/w3_reversal.py` 可重建两组证据。主比较和补充比较分别保存。浏览器和 Python 使用相同的存档内容指纹，归一化 JSON 中数值相同的整数与浮点写法。
- 运行 `python3 -m unittest discover -s living_world/tests -v` 检查 W1–W3 核心和 HTTP。29 项通过，其中 8 项覆盖 W3。传播判定的单元测试使用专设状态，报告中的 18 对来自从零运行的世界。[测试记录](review/tests.txt)
- 12 项独立 Chromium 检查通过，覆盖真实文件选择器导入、零差异、同步回放、案例关键时刻和窄屏。按 W2 开发说明设置 Playwright 路径后，执行 `node living_world/tests/browser-w3.cjs`。[浏览器验证记录](review/browser-verification.json) · [同伴改选截图](review/w3-relay.png)
