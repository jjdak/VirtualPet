# W6 · 方格小世界

从 main 的 W5 里程碑记录 d53bf20 开始。Astra 负责范围、核对和记录，GPT‑6.2 Sol 编写实现与测试。

1. 在浏览器本地运行固定步长的持续方格世界。四名居民由种子生成，各自的性格和能力实际影响探索、移动或感知；资源随时间变化。保留暂停、单步、连续运行和快进几趟。
2. 玩家可在所选时刻给小岚一次地点建议。留住提醒前的完整状态，按相同世界时间独立推进无干预分支；既能回到提醒前观察，又能对照随后同序出发的目的地、亲历和节奏。
3. 提供无预设含义的符号与可选择沉默的交流渠道。接收者通过亲历积累证据，发送者能根据反馈调整行为。用多个种子，对照正常、消音或置换，报告使用、听者行动和实际收益。允许没有形成稳定约定。
4. 使用种子、规则版本、时刻与玩家输入重放，支持刷新恢复，避免逐帧保存历史。记录快照、重算与数据量的取舍，核对重放一致和分支隔离。
5. 新入口独立于 W5；实际验证桌面和窄屏操作，保存截图与可复现记录，提交指向 main 的短期 PR。玩家体验待试玩。
