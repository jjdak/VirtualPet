# W2 情境经验计划 · 2026-11-06

先固定机制和检验，再运行实验。以 W1 的行动、取食、同伴通信、玩家建议和存档为基础。角色可直接观察“晴天／雨天”；两个地点的位置和供给规则沿用 W1。设计者规定天气分类，角色通过到访学习每种天气下各地的效果。

1. 增加两种可见天气。默认每 80 步交替，初始晴天青禾有益、紫穗不适，雨天相反。玩家可以固定天气、恢复交替、修改当前天气的食物效果、改变地点供给、给单个角色地点线索。供给跨天气共用。
2. 每个角色按天气分别保存亲历次数、收益估计、同伴报告与验证记录。选择读取出发时的天气，取食按抵达取食时的天气记账。切换天气本身不会产生经验。地点建议仍为短期的个人建议。
3. 界面显示当前天气、切换控制、两种天气的记忆对照及实际决策依据。使用独立 W2 端口/存档目录，v2 完整保存两套记忆和天气时钟。保留 W1 入口和旧存档。
4. **受控检验**：两种天气、两个地点、相反经历，平衡总样本数。分别测同一人换天气、同天气不同人、交换经历和相同经历。在同一随机输入下与忽略天气、合并经历的对照比较，预设种子 0–31；报告所有结果，包含探索失误。实验员安排接触，不将其解释为自主发现。
5. **自由运行**：32 个种子，每个 960 步，默认交替和近距离分享。按天气比较记忆分开与合并策略的实际取食有益率，前 160 步单列。记录同人不同天气的选择、两人实际分歧与可能原因，避免将偶然分歧归因于学习。
6. 检查途中变天、证据隔离、旧消息不会跨天气验证、定向线索、存档精确续跑和坏档。用隔离浏览器操作天气、个人面板、干预和存取档。阶段回执与进展统一放在本目录，公开结论以可复核结果为限。
