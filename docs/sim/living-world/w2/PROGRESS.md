# W2 情境经验 · 2026-11-06

**角色能根据亲历区分同一地点在晴天和雨天的不同效果。两人的经历不同时，固定随机输入也可以得到不同选择。** 本轮先登记[计划](PLAN.md)，再实现、运行受控对照与自由生活检验。天气是设计者给定、两人均可观察的分类；要学习的是地点在各天气下的价值。

## 先体验一次

运行 `./living_world/w2.command`，打开 <http://127.0.0.1:4194/>。“载入双人示例”会在确认后载入晴天第 700 步，并保留替换前的恢复副本。切换阿禾和小岚，查看亲历表，再点击“开始生活”。若想重新比较，可再次载入同一示例，出发前给其中一人线索或切换雨天。

示例从空记忆的种子 0 自由运行至第 480 步，再通过正常玩家操作固定晴天、将青禾改为不适、紫穗改为有益。随后自由运行至第 700 步。此时阿禾仍将晴天青禾估为 +1.00，小岚已估为 −0.28。保持环境，阿禾第 713 步选青禾，小岚第 736 步选紫穗，这两次都是基于估计的选择。示例是为观察差异事后选取的时刻，与下面的固定比较分开。[交互存档](review/step700-example.json) · [下一次选择及分数](review/comparison.json) · [界面](review/w2-desktop.png)

## 受控比较

每人先在两种天气下各亲尝两个地点，一共四次。反向经历通过改变接触时的实际效果构造，实验员安排接触。各人的总样本数、正负反馈数相等。32 个种子轮换天气接触顺序，用同一时刻、同一随机输入读取两人的选择。探针读取副本，排除在途动作、玩家线索、转述与角色随机盐值的干扰。合并对照沿用同一选择规则，把每人的两种天气经验存在一起。

| 观测 | 分天气记忆 | 合并记忆 |
| --- | ---: | ---: |
| 选择符合该人、该天气的亲历 | 116/128 | 64/128 |
| 同一人换天气后改选 | 52/64 | 0/64 |
| 相反经历下两人选择不同 | 52/64 | 52/64 |
| 对调两人经历后两人均改选 | 52/64 | 52/64 |
| 相同经历和相同随机输入下两人选同处 | 64/64 | 64/64 |

观察“两人选不同处”本身无法区分两种策略。区别在于同一个人能否随天气调用相应经历。种子 0 的反向经历探针中，晴天阿禾选青禾、小岚选紫穗，雨天两人分别改选紫穗、青禾。保留了原有偶尔探索，表中包含探索时的选择。

## 自由运行

每种策略用相同的 32 个种子各运行 960 步，每 80 步交替天气。保留需求、逐格移动、探索和近距离通信。按实际取食时天气统计有益餐数。策略不同会改变饥饿及下次出发时间，因此两组实际餐数也会不同。

| 时间段／天气 | 分天气记忆有益餐／总餐 | 合并记忆有益餐／总餐 |
| --- | ---: | ---: |
| 前 160 步 · 晴 | 95/161（59.0%） | 95/163（58.3%） |
| 前 160 步 · 雨 | 95/129（73.6%） | 24/206（11.7%） |
| 后 800 步 · 晴 | 504/664（75.9%） | 469/768（61.1%） |
| 后 800 步 · 雨 | 447/631（70.8%） | 283/931（30.4%） |

后 800 步先算每个种子的有益取食率，再等权平均，得到 **73.5% 对 44.6%**，32/32 个种子均提高。这个比较同时包含按天气区分亲历与同伴报告的作用。两种固定天气、确定的相反收益和固定周期限制了结论范围。

同一天气段内配对两人最近的出发选择，分天气组有 144/766 对目标不同，合并组为 191/916。出发时间、个人记忆、同伴信息和随机探索在自由运行中共同影响选择。两人都学过相同规律后也会趋同，第 480 步存档可直接检查这种情况。[原始统计与逐种子结果](review/comparison.json) · [第 480 步存档](review/seed0-step480.json)

## 玩家干预与存档

天气默认自动交替，玩家可固定晴天、固定雨天或重新开启交替。改变食物效果只作用于当前天气，开放／停供跨天气共用。服务按玩家提交时看到的天气校验设置，避免在切换瞬间误改另一套效果。地点建议仍只交给选定角色，沿用 W1 的时效与权重。

角色在出发时用当前天气的个人经验评分；途中变天后，实际触及食物时才按新天气更新。旧天气的亲历和消息留在对应记忆中，返回该天气时才参与评分与交流，原时间戳和消息有效期保留。每个人对同伴消息的验证也分天气进行。界面按角色展示两个天气下的亲历次数、价值以及真实行动理由。

W2 使用 v2 格式和独立目录 `.runtime/living-world-w2/`。存档保存两套记忆、两种天气的效果、时钟、角色任务和建议。W1 的存档继续通过 `living_world/run.command` 和 4193 端口使用。W2 会拒绝缺少天气信息的 v1 导入。
