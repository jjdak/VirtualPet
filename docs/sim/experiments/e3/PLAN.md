# E3：意外之后，是否值得主动复查

日期 2026-11-01。用户授权实现 E3、参考近期研究并维护整洁目录。本计划与 `protocols/e3-v1.json` 在批量运行前固定；不按结果调参。E1/E2 的源码、数据与回放保持。

## 问题与范围

两角色仍在 E2 网格中选择两种食物，个人经验和信任独立。复查会占用一次正常取食机会，照常移动、承担收益/损失；没有免费查看另一食物的结果。目标是检验定向复查是否改善环境变化后的适应，以及稳定噪声下的误触发成本。不是神经网络训练、语言反思或自发人格。

## 预定比较

所有策略均沿用 E2 近期价值更新、来源可靠度更新及分享规则。

| 策略 | 随机探索概率 | 额外机制 |
| --- | --- | --- |
| random_12 | 0.12 | E2 基线 |
| random_24 | 0.24 | 用更多随机探索检验试错成本 |
| surprise_random | 0.12 | 达到意外触发条件后，下一回合随机试一种食物 |
| surprise_stale | 0.12 | 相同触发条件，下一回合复查另一个长期未亲自取食的选项 |

触发：已亲历某食物至少 3 次，连续两个回合选择同一种食物，个人预测与结果的绝对差均 ≥1.0；另一个食物已亲历但至少 8 回合未复查。消息内容不触发检测。触发后下一回合执行一次探查；同一角色两次探查至少间隔 8 回合，最多 6 次。更新价值仍为 EMA 0.4，不直接清空/反转旧价值。未知食物照旧优先尝试。随机触发对照与定向复查上限相同，但实际次数可能因反馈路径不同而不同，不能称为严格等次数对照。

## 情景与采样

每组 100 个固定种子（0–99）、120 回合、2 个角色；6 情景×4 策略＝2,400 episodes、576,000 次取食选择。

1. 稳定：效果不变。
2. 互换：回合 40 起两食物收益互换。
3. 互换＋旧消息：沿用 E2 甲重复回合 39 记录。
4. 稳定＋噪声：每次取食有 10% 概率反转结果，隐藏期望收益不变。
5. 互换＋噪声：互换叠加相同噪声，用于检测灵敏度。
6. 隐蔽改善：原优选始终 +0.5；原劣选在回合 40 从 -1 改为 +1。检验“只盯当前选择的意外”是否漏掉别处改善。

随机数按种子/回合/角色/食物确定，策略共享同一外源随机环境；角色无情景名、变化时刻、潜在收益和其他角色私有状态。完整轨迹只保留预定种子 0；其余保存摘要并可复算。噪声真实收益与评价用期望收益分开。

## 主要指标

- 乙在回合 40–59 的期望最优选项选择率；每个配对种子的差值及 95% 配对 bootstrap 区间（2,000 重采样、固定种子）。区间描述这些人工种子的均值不确定性，不代表跨任务泛化。
- 全程动态伪遗憾：每步最佳期望收益减实际所选的期望收益；越小越好。不是事后看噪声结果选赢家。
- 全程实际收益、随机探索/主动探查次数、探查选择劣项的次数与伪遗憾成本。
- 变化后首次连续 5 次选择期望最优项的时间；未恢复单独报告，只在变化情景解释。
- 稳定环境触发次数是误触发指标；还记录冷却/预算阻止次数与触发原因。不以“善用信任”解释神谕式全知。
