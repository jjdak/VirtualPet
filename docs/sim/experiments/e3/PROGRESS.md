# E3 进展与结果

2026-11-01。状态：计划内实现、固定参数批量运行、重算审计、跨进程恢复、并排回放与浏览器操作检查完成；主观趣味性待用户评价。未开始下一阶段。

## 本轮结论

**连续意外后复查旧选项，在本实验的突然互换情景有效；噪声会导致额外损失，别处悄悄改善时则没有增益。** 这是一项有适用条件的启发式策略，不是通用反思或自我进化。

原 E2 近期价值表与信任机制不变，在 E3 新目录里增加个人预测残差监测、证据年龄、下一回合探查队列、次数与冷却限制。复查仍需真实走过去取食，承担该回合的机会成本，不免费获知另一食物收益。两角色先作决定，随后各自获取结果，最后回营通信。分享意愿和运动控制没有学习。

## 固定协议与执行

- [计划](PLAN.md) 和 [配置](../../../../experiments/reinspection_agents/protocols/e3-v1.json) 在批量运行前固定。6 情景×4 策略×100 种子，2,400 episodes，576,000 次选择。
- 全部策略 120 回合、相同价值更新与通信条件；额外随机对照为 24%，触发随机/定向对照均保留基础 12% 探索。未按结果调参或筛选成功种子。
- 主运行 50.24 秒，Python 3.11.15、标准库，无模型调用/新依赖。这是批处理耗时，不是动画帧率或 LLM 性能数据。
- 每种情景/策略预定保留种子 0 完整轨迹，共 24 条；全部 2,400 组保留摘要并能确定性重算。结果含源码、E2 依赖源码、计划和配置指纹。

## 比较结果

以下是乙在回合 40–59 选择**期望收益最优项**的比例，100 种子平均。噪声下它不同于“实际这口是否有益”。

| 情景 | 随机 12% | 随机 24% | 意外触发随机探查 | 意外触发定向复查 |
| --- | ---: | ---: | ---: | ---: |
| 稳定 | 94.85% | 88.65% | 94.85% | 94.85% |
| 效果互换 | 58.15% | 68.30% | 72.95% | **83.65%** |
| 互换＋旧消息 | 36.50% | 56.00% | 48.75% | **65.05%** |
| 稳定＋10% 噪声 | **94.05%** | 87.80% | 93.75% | 93.35% |
| 互换＋10% 噪声 | 66.45% | 73.05% | 74.45% | **77.85%** |
| 别处悄悄改善 | 56.10% | **66.15%** | 56.10% | 56.10% |

关键的成本与证据：

1. **互换＋旧消息**：定向复查相比普通随机，改善 28.55 个百分点，配对 bootstrap 95% 区间 [22.60, 34.85]；相比同触发条件的随机探查，改善 16.30 个百分点，区间 [11.30, 21.60]。两触发策略在此情景平均均执行 0.63 次探查；总体仍不能假设所有情景探查次数完全匹配。恢复中位数由随机 12% 的 19 回合降至 10 回合，触发随机为 15 回合、随机 24% 为 13 回合。
2. **总损失更少**：上述情景全程动态伪遗憾从 46.64 降至 29.00；随机 24% 为 43.06，触发随机为 38.56。伪遗憾是错过的期望收益，越低越好；不是看见当次随机结果后挑选最优项。
3. **稳定噪声的误报成本**：定向策略平均安排 0.97 次、实际执行 0.95 次探查（少量在最后一回合安排，实验截断前未执行）。它的全程伪遗憾 16.08，高于普通随机的 14.56，差值 +1.52，95% 区间 [1.264, 1.792]。检测器取绝对误差，甚至可能把噪声后的收益恢复也当作第二次意外；这一局限如实保留，未为改善本轮成绩修改阈值。
4. **带噪互换的优势没有那么坚实**：定向复查比触发随机的窗口选择率高 3.40 个百分点，但全程伪遗憾差值 -0.496 的区间 [-1.488, 0.256] 包含 0，不能声称它在这个指标上稳定更好。
5. **没有意外就没有触发**：隐蔽改善情景里，定向策略与随机 12% 所有配对种子的这两项指标完全相同；未获得额外收益。随机 24% 在变化窗口发现改善更快，但全程试错更多，伪遗憾 15.155 高于低探索策略的 11.835。

稳定无噪声世界没有主动探查，定向策略等于普通随机。各变化情景中，四策略的 100 个种子均在结束前达到了连续 5 次最优选择的恢复标准。这个标准不代表永远不再犯错。区间由 2,000 次固定种子的配对 bootstrap 得到，没有多重比较校正，只说明该人工任务的采样变化。

## 可在回放中看到的具体行为

- **有效复查**：互换＋旧消息 / 种子 0。回合 40、41 连续异常；回合 41，乙发现紫穗已 28 回合未亲历，安排复查。回合 42 普通随机乙仍吃青禾（-1），定向复查乙吃紫穗（+1），个人价值由 -1 更新到 -0.2；没有直接改成“正确答案”。
- **无效复查**：稳定噪声 / 种子 0。回合 101 触发，102 改吃仍较差的紫穗；乙累计伪遗憾从 9.6 增至 11.2，基线维持 9.6。
- **遗漏改善**：隐蔽改善 / 种子 0。“定位首次触发”明确显示没有触发，仍靠基础随机探索或通信发现变化。

页面左侧可以切换三种对照，右侧固定定向复查；同种子同回合并排显示。平均表与种子 0 轨迹分开，图中完整曲线仅供观察者查看，不是角色输入。

## 验证

- **12 项 Python 测试通过**：单次异常不触发、连续误差/延迟执行、不免费改价值、个人证据与消息隔离、旧证据年龄、冷却/预算、随机触发对照、E2 基线逐步一致、噪声潜在收益、独立状态、跨进程待执行探查恢复、完整恢复/截断、独立审计拒绝损坏数据与区间计算（部分在同一测试方法中）。
- 重新计算全部 2,400 组和 576,000 次选择；摘要与存档一致。独立审计 24 条采样轨迹、51,840 个物理动作及其触发证据、收益、消息、预算和截断。
- 页面逻辑替身检查 18 种情景/对照组合、8,640 张状态卡片与播放换回合；真实浏览器另行检查首次触发、播放/暂停、滑块、三个对照、噪声和隐蔽改善情景。
- 浏览器截图已经目视检查：桌面并排布局与表格可读。没有声称移动端、严格帧率或真人趣味性验收。
