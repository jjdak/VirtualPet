## 恢复与使用

```bash
git clone --branch agent-lab-e1-e5-2026-11-02 https://github.com/jjdak/VirtualPet.git
cd VirtualPet
python3.11 -m http.server 4191 --bind 127.0.0.1 --directory experiments/frequency_agents/results
```

浏览 `http://127.0.0.1:4191/e5-v1/replay.html`，或直接打开相应离线 HTML。复算/重新实验遵循每轮 README，写入新的结果目录，不覆盖历史证据。E5 页面页脚更正由独立脚本记录，冻结批次源码保持。
