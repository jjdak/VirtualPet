## 🔧 技术架构

### MVVM 架构
```
Views (UI层)
  ├── ContentView (主视图)
  ├── Components (组件库)
  │   ├── PetDisplayView
  │   ├── StatusGridView
  │   ├── FoodSelectionView
  │   ├── MiniGameHubView
  │   └── ...
  └── Managers (管理器)
      ├── HapticManager
      ├── ComboSystem
      └── AudioManager

ViewModels (业务逻辑层)
  └── Pet (核心业务逻辑)

Models (数据模型层)
  ├── Pet (宠物模型)
  ├── Activity (活动记录)
  ├── Achievement (成就)
  └── Enums (枚举定义)
```

### 设计模式
- **MVVM**: 清晰的职责分离
- **单例模式**: HapticManager, ComboSystem
- **观察者模式**: @ObservedObject, @Published
- **策略模式**: EvolutionPath, PetType
- **工厂模式**: Activity, Achievement 创建

### 数据持久化
- UserDefaults (简单数据)
- JSON 编码 (复杂对象)
- 自动保存 (每次交互后)
