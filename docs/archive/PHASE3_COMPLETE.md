## 🔧 技术实现总结

### Codable处理策略

**问题**: 复杂枚举和结构无法直接序列化

**解决方案**:
1. **枚举使用rawValue**:
   ```swift
   enum BattleResult: String, Codable {
       case win = "win"
       case lose = "lose"
   }
   ```

2. **字符串存储**:
   ```swift
   let petTypeString: String  // 存储"🐱"
   var petType: PetType {     // 读取
       PetType(rawValue: petTypeString) ?? .cat
   }
   ```

3. **自定义CodingKeys**:
   ```swift
   enum CodingKeys: String, CodingKey {
       case id, name, petTypeString  // 排除计算属性
   }
   ```

### 状态管理模式

**单例模式 + @Published**:
```swift
class LeaderboardManager: ObservableObject {
    static let shared = LeaderboardManager()
    @Published var levelEntries: [LeaderboardEntry] = []
}
```

**优势**:
- 全局唯一实例
- 响应式状态更新
- 便于多组件共享

### 数据持久化

**UserDefaults + JSON编码**:
```swift
private func saveData() {
    if let data = try? JSONEncoder().encode(entries) {
        defaults.set(data, forKey: "key")
    }
}
```

**适用场景**:
- 简单键值对
- 复杂数据结构
- 用户偏好设置

## 🎓 技术难点解决

### 难点1: Codable兼容性

**问题**: PetType等枚举无法直接序列化

**解决**:
- 使用字符串存储
- 计算属性转换
- 自定义CodingKeys

**代码示例**:
```swift
let petTypeString: String  // 存储
var petType: PetType {     // 读取
    PetType(rawValue: petTypeString) ?? .cat
}
```

### 难点2: 排名变化计算

**问题**: 排名变化需要准确追踪

**解决**:
1. 记录旧排名
2. 更新分数
3. 重新排序
4. 计算新排名
5. 变化 = 旧排名 - 新排名

**代码示例**:
```swift
let oldRank = index + 1
entries.sort { $0.score > $1.score }
let newRank = newIndex + 1
let change = oldRank - newRank
```

### 难点3: 战斗状态管理

**问题**: 回合制战斗状态复杂

**解决**:
- isPlayerTurn标记回合
- 每回合切换
- 检查战斗结束
- 技能冷却减少

**代码示例**:
```swift
if battleManager.isPlayerTurn {
    // 玩家选择技能
    executeSkill(skill, isPlayer: true)
    battleManager.isPlayerTurn.toggle()
}
```
