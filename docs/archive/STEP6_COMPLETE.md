## 📊 功能详情

### 1. 记忆卡片游戏

#### 游戏机制
- **卡片数量**: 16张 (8对)
- **图标**: 🐶🐱🐼🦊🐨🐯🦁🐮
- **时间限制**: 60秒
- **游戏目标**: 找出所有配对

#### 计分系统
```swift
分数 = 匹配奖励 (50/对) + 时间奖励 (剩余秒数 × 2) - 步数惩罚 ((步数 - 8) × 5)
```

#### 等级标准
- **S级**: ≥300分
- **A级**: ≥250分
- **B级**: ≥200分
- **C级**: ≥150分
- **D级**: <150分

#### UI组件
- **卡片视图**: 正面/背面3D翻转动画
- **进度显示**: "已配对: X/8"
- **结果界面**: 等级、分数、步数、剩余时间

#### 游戏流程
1. 16张卡片背面朝上
2. 点击翻第一张
3. 点击翻第二张
4. 检查匹配:
   - 匹配成功 → 保持翻开 +10分
   - 匹配失败 → 0.8秒后翻回
5. 全部匹配完成或时间到 → 结束

### 2. 反应测试游戏

#### 游戏机制
- **时间限制**: 30秒
- **目标数量**: 同时最多5个
- **生成间隔**: 1秒
- **目标存续**: 1.5-3秒随机
- **目标大小**: 40-70像素随机

#### 计分系统
```swift
基础分 = 10分
加成 = combo × 0.5
得分 = 基础分 × (1 + 加成)
```

#### Combo系统
- 连续命中 → combo +1
- 目标过期未点 → combo清零
- Combo加成 → 最多2.0x (combo=4)

#### 统计数据
- **命中数**: 成功点击的目标
- **失误数**: 过期未点目标
- **准确率**: 命中 / (命中 + 失误)
- **最大连击**: 单局最高combo

#### 等级标准
- **S级**: 准确率≥90% 且 分数≥500
- **A级**: 准确率≥80% 且 分数≥400
- **B级**: 准确率≥70% 且 分数≥300
- **C级**: 准确率≥60%
- **D级**: 准确率<60%

#### UI组件
- **目标视图**: 倒计时外圈 + 渐变圆圈
- **统计面板**: 命中/失误/combo显示
- **结果界面**: 等级、分数、准确率、最大combo

#### 游戏流程
1. 游戏开始,倒计时30秒
2. 每秒随机生成1个目标
3. 目标在1.5-3秒后消失
4. 点击目标 → 得分 + combo
5. 过期未点 → 失误 + combo清零
6. 时间到 → 游戏结束

## 🔧 技术实现

### 数据模型

#### MemoryCard (记忆卡片)
```swift
struct MemoryCard: Identifiable {
    let id: UUID()
    let emoji: String
    var isFlipped: Bool   // 是否翻开
    var isMatched: Bool   // 是否已匹配
}
```

#### TargetPoint (目标点)
```swift
struct TargetPoint: Identifiable {
    let id: UUID()
    let position: CGPoint      // 位置
    let size: CGFloat          // 大小
    let lifetime: TimeInterval // 存续时间
    let createdAt: Date        // 创建时间
    var isHit: Bool            // 是否被击中

    var isExpired: Bool         // 是否过期
    var remainingProgress: Double // 剩余进度 (0-1)
}
```

### 核心算法

#### 翻牌匹配逻辑
```swift
1. 翻第一张 → 加入flippedCards数组
2. 翻第二张 → 加入flippedCards数组
3. 检查数组长度 == 2:
   - 匹配成功 → 标记isMatched, 清空数组
   - 匹配失败 → 等待0.8秒, 翻回两张, 清空数组
4. 所有卡片匹配 → 游戏结束
```

#### 目标生成算法
```swift
// 随机位置 (避免边缘)
padding = 50
x = random(padding, screenWidth - padding)
y = random(padding, screenHeight - padding)

// 随机大小
size = random(40, 70)

// 随机存续时间 (越小存续越短)
lifetime = random(1.5, 3.0)

// 限制同时存在数量
if targets.count > 5: removeFirst()
```

### 动画效果

#### 3D翻转动画
```swift
.rotation3DEffect(
    isFlipped ? .degrees(180) : .degrees(0),
    axis: (x: 0, y: 1, z: 0)
)
```

#### 倒计时进度环
```swift
Circle()
    .trim(from: 0, to: remainingProgress)
    .stroke(Color.orange, lineWidth: 4)
    .rotationEffect(.degrees(-90))
    .animation(.linear(duration: 0.1), value: remainingProgress)
```
