# B2 光色静帧与八秒动态小样

2026-09-14：用户明确要求「一张光色调整后的静帧＋约 8 秒的动态小样」，授权从静态入景进入本轮原生动画制作。源工程是 `courtyard-b1-girl-a-v3.blend`；不重跑迁移、不改人物网格、不接聊天/学习系统。

## 本轮设计

- 减少均匀环境填光，强化温暖定向日光，保留偏冷的天空补光；人物水边增加柔和暖反射光。
- 固定原相机与完整庭院布局，少女A沿用现有身体骨架和静态脸。
- 水面：闭合水体保留，材质里的噪声与坐标有连续、可循环的关键帧，变化的是表面法线/反光，不是流体求解。
- 树冠：10 个叶簇围绕各自中心小幅错相摆动，1.3–5 秒间有一次较明显的风，原始叶片网格保持。
- 人物：轻微肩背呼吸，风起后约 2.3 秒开始转头，约 3.8 秒达到目标，停留后于约 7.3 秒恢复。没有眼球/眼睑动作。
- 手臂逐帧求解后烘焙成普通骨骼关键帧，撑手和落腿手保持原落点。非物理布料模拟，不能从关节落点推断裙摆无任何穿插。

## 工程与检查

`blender/scripts/author-b2-study.py` 生成独立原生工程；`verify-b2-study.py` 重开后检查真实人物顶点、手腕漂移、水材质变化、叶簇运动及首尾帧一致性；`render-b2-preview.py` 从保存工程渲染 PNG 序列，不写回工程。

时间轴为 24 fps，渲染帧 1–192，时长 8 秒；193 是检查用循环终点，不重复写入视频。所有动作是 Blender 原生关键帧，不依赖外部运行时、脚本 handler 或网页。单帧使用 Cycles 1280×720/64 samples；动态小样使用 Cycles 960×540/24 samples，与静帧同一光色工程。

当前状态（2026-09-19）：静帧与 8 秒视频已交付；原生动作、重开、192 帧完整性与整段视频解码检查通过。已检查静帧与视频解码后第 1/60/96/150/192 帧，未见明显姿态跳变或接触位置突变。完整播放的闪烁、动作可读性和主观静谧感仍待观看验收。

主观验收关注：是否安静但不僵硬；风与人物回应是否有先后关系；动作是否太微弱或太刻意；水面和树影是否闪烁；八秒循环边界是否明显。无声音、交互或学习，不能将预排小样叫作实时响应。
