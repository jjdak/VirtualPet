# P8 / B2 v7 树冠小样 — 2026-10-09

上一轮 P7 完成社区研究和 v6 光色对照，属于实际进展。本轮按已记录的下一动作，改善现有树冠塑料片般的亮暗碎块；不新增装饰或人物模型。

## 计划

1. 从 v6 focused 另存两个有限候选：soft 只加薄叶透光材质；slender 同材质并将现有叶片宽度缩至 68%、长度缩至 94%。保留枝条、叶片中心、簇位置和原风动画。
2. 两版均保留人物、石阶等非树冠网格、相机、灯光和全部关键帧。透光混合比 26%，不是自发光，不改变日光方向。
3. 先查看 960×540 草稿，选择或否决；只有有可见改善的候选才渲染正式静帧及峰值动作帧。
4. 保存工程、前后对照、源文件哈希和变化检查。未决定采用前不把候选升级为主工程；不重渲染整片。

实施脚本：`blender/scripts/refine-b2-canopy.py`。三版试做与选定候选的正式帧已完成；主工程仍为 v6 focused，v7 balanced 为可比较候选。


## 实际结果

- soft：原 B1 材质已有 22% 透光，本次提高至 26%，变化很小，未选为交付候选。不能把它描述为从无到有加入透光。
- slender：叶宽 68% 让树冠更通透，但亮暗细节更碎，未采用。
- balanced：一次有界修正，叶宽改为 82%、叶长 94%，只给 10 组树冠链接一盏 220 W、4 m 的柔和天空补光。选为本轮候选，树冠暗面较浅、枝叶间隙更清楚；更淡的叶色属于审美取舍，不推断用户已认可。

保留 1,680 片叶子及原簇中心/枝条位置，无新增外部素材或插件。缩叶改变真实树影，非人为画到图上的后期效果。非树冠网格、相机、对象布局及全部动作保持；人物与服装未改。补光是新增灯光对象，不是新增场景道具。

正式输出 1280×720 / 128 samples 的帧 1、101、193。另一个 Blender 进程重开后的完整指纹与作者记录相符，源 v6 哈希保持；帧 1/193 的 160×90 灰度差为 0。已查看正式静帧、峰值姿态与同机位对照。此项不证明全片自然度，当前视频仍为 v5 光色。
