## 🎊 项目概览

VirtualPet 是一个功能丰富的iOS虚拟宠物养成游戏,采用现代SwiftUI框架开发,支持iOS、macOS和visionOS多平台。游戏包含完整的宠物养成系统、小游戏、社交、公会、对战等丰富玩法。

### 核心特色

- 🐱 **5种可爱宠物**: 猫咪、狗狗、兔子、仓鼠、小鸟
- 🎮 **5个休闲小游戏**: 觅食大作战、玩具接接乐、清洁大作战、记忆卡片、反应测试
- 👥 **完整社交系统**: 好友互动、亲密度培养、社交送礼
- 🏰 **公会系统**: 创建/加入公会、成员管理、公会任务
- ⚔️ **PVP对战**: 回合制战斗、技能系统、天梯排行
- 🏆 **排行榜系统**: 多维度排名、好友排行、天梯积分
- 📋 **每日任务**: 8种任务类型、连胜奖励、钻石货币
- 🛍️ **商店系统**: 食物、道具、特殊商品
- 🌟 **进化系统**: 7个进化阶段、5条进化路径
- ⚡ **技能系统**: 技能点、技能树、能力强化

## 🎯 核心游戏机制

### 宠物养成

**属性系统**:
- 饥饿度 (0-100): 每分钟+1
- 快乐值 (0-100): 每分钟-1
- 健康值 (0-100: 根据其他属性计算
- 能量值 (0-100): 每分钟-2
- 经验值: 通过互动获得
- 等级: 经验累积升级

**心情系统** (7种):
- 开心、正常、饥饿、伤心、生病、兴奋、困倦

**进化系统**:
- 7个阶段: 蛋→宝宝→儿童→少年→成年→老年→远古
- 5条路径: 平衡型、力量型、快乐型、健康型、神秘型

### 经济系统

**货币**:
- 钻石: 特殊货币,任务和商店获得
- 经验: 宠物升级

**消耗**:
- 喂食/玩耍/锻炼消耗能量
- 商店购买消耗钻石
- 社交送礼消耗钻石

### 社交系统

**亲密度等级** (0-100):
- 0-19: 陌生人
- 20-39: 认识
- 40-59: 朋友
- 60-79: 好友
- 80-99: 挚友
- 100: 死党

**互动奖励**:
- 访问: +5亲密度 (1小时冷却)
- 送礼: +10亲密度 (2钻石)
- 玩耍: +3亲密度
- 留言: +2亲密度

### 对战系统

**技能**:
- 普通攻击: 20威力, 无冷却
- 特殊技能: 35威力, 2回合冷却, 10MP
- 防御姿态: 减伤, 3回合冷却, 5MP
- 治疗术: +30HP, 4回合冷却, 15MP
- 终极技能: 50威力, 5回合冷却, 25MP

**天梯积分**:
- 胜利: +25分
- 失败: -20分
- 赛季奖励: 前10/50/100/500名获得称号和钻石

## 🔧 技术架构

### 开发环境

**语言**: Swift 5.0
**框架**: SwiftUI
**平台**: iOS 26.2, macOS 26.1, visionOS 26.2
**IDE**: Xcode
**架构模式**: MVVM

### 核心技术

**UI框架**:
- SwiftUI声明式UI
- @Published响应式状态
- @ObservedObject状态管理
- @StateObject本地状态
- @Binding双向绑定

**数据持久化**:
- UserDefaults: 简单数据存储
- JSON编码: 复杂数据序列化
- NSDictionary: 库存管理

**并发处理**:
- Combine框架: 响应式编程
- DispatchQueue: 延迟操作
- Timer: 定时任务

**动画效果**:
- SwiftUI内置动画
- 3D旋转效果 (rotation3DEffect)
- 粒子效果 (drawingGroup)
- 弹簧动画 (.spring())
- 渐变动画 (LinearGradient)

### 设计模式

**MVVM架构**:
- Model: Pet, Friend, Guild等数据模型
- View: SwiftUI视图组件
- ViewModel: Pet等ObservableObject

**单例模式**:
- DailyTaskManager.shared
- ShopManager.shared
- SocialManager.shared
- GuildManager.shared
- BattleManager.shared
- LeaderboardManager.shared

**观察者模式**:
- @Published属性发布变化
